Pairing Matrix · V1 rules

Normal retrieval / LADC selects the first successfully admitted direct memory as the primary seed. Pair weight W never changes direct retrieval or admission.

Inspect stored outgoing typed relationships in the recorded current context. Choose the highest accepted/resolved contextual W above neutral; exclude targets already returned directly. Ties use a stable edge identity, with no semantic priority.
