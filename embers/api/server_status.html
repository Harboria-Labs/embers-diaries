Coverage and privacy

Only public, side-effect-free endpoints are actively checked. Memory, retrieval, feedback, sessions, grants, configuration APIs and private namespace endpoints are excluded. A healthy page does not prove the underlying protected operation works.

CPU, RAM, storage and model health: Not observed. Missing model data is never a failure signal.
